📦 addon-ez-bedrock-loader - Manage game add-ons with ease

Visit the download page

The addon-ez-bedrock-loader helps you find and install add-ons for your favorite sandbox game. You do not need technical skills to use this tool. It handles the preparation of files so you can play your game with new features right away.

🛠️ System Requirements

Your computer must meet these basic needs to run the software:

  • Windows 10 or Windows 11.
  • An active internet connection.
  • A modern web browser like Chrome, Edge, or Firefox.
  • The base sandbox game installed on your local drive.

📥 Download and Setup

Follow these steps to get the loader on your computer:

  1. Go to the official repository page to start your download.
  2. Click the release link on that page to save the setup file to your computer.
  3. Open your Downloads folder and double-click the file to start the installation.
  4. Follow the prompts on your screen.
  5. Select the folder where your game files exist when the program asks for a path.

🎮 How to Load Add-ons

Once you finish the setup, you can add content to your game through the web interface:

  • Open the application from your desktop or start menu.
  • Browse the list of available add-ons within the app.
  • Click the install button next to an add-on.
  • The loader puts the files in the correct game folder for you.
  • Restart your game to see the new content in your menus.

⚙️ Troubleshooting Tips

If you face issues, check these common items:

  • Add-ons do not show: Ensure the loader points to the correct game directory in the settings menu.
  • App does not open: Check if your antivirus software prevents the app from running and allow it.
  • Connection errors: Check your internet connection and restart the app.
  • Updates: The app checks for new versions automatically when you open it. Always use the latest version.

🌐 Local Serving

Advanced users can host a local version of this loader. You can run the interface through your local network if you wish to manage add-ons from different devices. The settings menu includes a toggle for local server mode. When you enable this, the app provides an IP address you can enter into any browser on your network.
