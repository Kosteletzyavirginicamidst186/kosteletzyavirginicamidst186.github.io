🤔 What Is yobiru?

Think of yobiru as a post office for your agents. Instead of you carrying information from one program to another by hand, your agents drop things off and pick them up themselves. One agent finishes a job and leaves a note. Another agent reads the note, grabs the file that came with it, and carries on. If an agent is idle, another agent can give it a gentle nudge to wake it up.

All of this happens on your own private network, created by a free tool called Tailscale. That means your messages and files do not travel through public servers, and strangers cannot see what your agents are saying. You stay in control, and your data stays with you.

yobiru is designed for people who want the power of connected agents without learning to code. You install it, you connect it to Tailscale, and you press a button. That is genuinely most of it.

✨ What You Can Do With It

  • Send messages between agents. Short notes, instructions, status updates, or questions. Anything one agent needs another to know.
  • Pass structured data. Results, lists, numbers, records. Hand off the output of one job as the input of the next without copying and pasting.
  • Share files. Documents, images, logs, or archives. Send a file once and let the receiving agent pick it up when it is ready.
  • Wake agents up. If an agent is sleeping or waiting, yobiru can send a wake-up so it starts working again at the right moment.
  • Stay private. Traffic runs over your Tailscale network, encrypted and addressed only to your own devices.
  • Keep a record. Messages and transfers are tracked so you can look back and see what happened and when.

🔁 Day-to-Day Use

Sending a message

Open yobiru, pick the agent you want to reach, type your note, and send. Messages are delivered as soon as the other side is reachable. If it is not reachable right now, yobiru holds the message until it is.

Passing data

Attach the information you want to hand over and send it the same way you would send a message. The receiving agent gets the data in a form it can use directly, so nothing has to be retyped.

Sharing files

Choose the file option, select your file, and confirm. Large files take longer, so give the transfer a moment before assuming something has gone wrong. A progress indicator shows you how far along it is.

Waking an agent

If an agent has gone quiet, use the wake-up action. This tells it that new work is waiting. It is the polite version of tapping someone on the shoulder.

🔒 Privacy and Safety

yobiru is built around Tailscale, which creates an encrypted private network between your own devices. Traffic never passes through public servers, and no one outside your network can see your messages or files. You do not need to configure firewalls, forward ports, or rent a server. Your devices simply find each other and talk directly.

Practical habits that keep things tidy:

  • Only share your Tailscale account with people you trust.
  • Remove old devices from your Tailscale account when you stop using them.
  • Keep yobiru updated from the same releases page so you always have the latest fixes.
  • Store received files in a folder you recognise, so nothing gets lost in your Downloads pile.

🛠 Troubleshooting

The download does not start

Refresh the releases page and try again. If your browser blocks the file, look for a small message near the top of the window and allow the download. Trying a different browser also helps when a download gets stuck.

Windows says the app cannot be run

This is Windows protecting you from unfamiliar files. Open the message, choose the option to keep the file, and then run it again. If the file appears to be blocked, right-click it, open Properties, and look for an option to unblock it.

yobiru cannot see my other device

Check that both devices are signed in to the same Tailscale account and both show as connected in the Tailscale app. Wake the other device from sleep, then reopen yobiru so it refreshes its list.

A file transfer stopped partway

Large files are sensitive to connection drops. Make sure both devices stay awake, then start the transfer again. Sending in smaller pieces is a reliable fallback.

Messages are delayed

If the other agent is busy or asleep, messages wait their turn. Use the wake-up action to prompt it. If delays continue, check that Tailscale is still connected on both ends.
